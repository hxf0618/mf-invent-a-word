Coins a new English word for make.fun's "Invent a Word We Need" bounty: **corridance** — the mirrored shuffle when two people block each other trying to pass in a hallway. The program writes the word and its one-line definition (95 characters) to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
